Capture per device (all land on the same /add?url=&text= screen):
Samsung S25 Ultra — install app, then Instagram → Share → Travel (Chrome or Samsung Internet).
iPhone / iPad Pro — Safari has no share target. Paste the copied link into search, or a one-time iOS Shortcut in the share sheet that opens Travel with the link.
Windows — copy link in browser → paste into desktop search box.
Layout — iPad Pro (either orientation) and Windows get the 3-column view; phones get the stacked view.

What is gone vs today: Routes tab · intent and tag filter chips · nearby transit · nearby stays · “Why this place” review mining · email / digest / notifications · username change · KML and GeoJSON import/export · continent-only region filter · intent as the primary nav.
What is new: City as the first-level object · district grouping · share-target capture on Android, paste-a-link on iPhone, with source link kept · “Open all in Google Maps” per city · Recent tab · paste-a-link search.
Kept: Google Places resolve on save · tags · notes · photos · swipe to edit/delete · export JSON · self-hosted Docker · optional login.
